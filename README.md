Generar los códigos HTML y CSS de 3 páginas Web con estas características (como mínimo esto, si agregan no hay problema, pero no pueden faltar estos):

PAGINA 1
NOMBRE:  index.html
Armar una Web donde recomienden: Libros o Películas o Series (con uno de los tres tipos está bien pero con varias recomendaciones, por lo menos 8), aplicando:

1. Estructura completa de HTML5 (además de Doctype, meta, html, head, body, aplicar div y span, aplicar todos los que vimos semánticos para estructuras HTML5 como header, nav, article, section, footer, details, aside, etc.)
2. Un menú tipo nav que nos lleve a diferentes zonas dentro de la Web
3. Imágenes con textos alternativos
4. Links en imágenes. Estos links deben abrir en pestañas nuevas
5. Por lo menos un video desde un archivo local (adjunto en el rar o zip) con controles en pantalla
6. Por lo menos un video tipo iframe de Youtube
7. Por lo menos un audio (mostrando los controles)
8. La primera recomendación debe tener un link a la página 2 que pedimos mas abajo, abriendo en la misma pestaña actual.
9. Se debe incluir un link "Encuesta" que lleve a la página 3 que pedimos mas abajo, abriendo en una pestaña nueva.
10. En el pie de página deben estar los datos del alumno autor de sitio
11. Aplicar todos los estilos CSS que sean necesarios para que la Web quede lo mejor posible. Debe ser un archivo especifico para este HTML.

PAGINA 2
NOMBRE:  desarrollo.html
Armar una Web relacionada con la Página 1 donde se desarrolle en detalle una de las series / noticias / libros de la Web principal.
Aplicar (por lo menos):

1. Estructura HTML completa (deben incluir doctype, meta, html, head, body, etc.)
2. Debe contener por lo menos un div y un span (más también)
3. Por lo menos una imagen con texto alternativo 
4. Por lo menos un video relacionado con el contenido desarrollado, ya sea archivo o iframe.
5. Tags para textos vistos en la materia
6. Párrafos y títulos
7. Una tabla (con mínimo 4 filas)
8. Listas ordenadas y sin orden
9. Links a sitios externos relacionados con el contenido que abran en ventanas nuevas
10. Link al sitio principal para volver a la página 1, este debe abrir en la misma ventana actual
11. Pie de página con los datos del alumno autor de sitio
12. Aplicar todos los estilos CSS que sean necesarios para que la Web quede lo mejor posible. Debe ser un archivo especifico para este HTML.

PAGINA 3
NOMBRE:  encuesta.html
En esta Web los visitantes podrán responder una encuesta en relación a los temas desarrollados en la página 1:

1. Estructura HTML completa (deben incluir doctype, meta, html, head, body, etc.)
2. Aplicar todos los estilos CSS que sean necesarios para que la Web quede lo mejor posible. Debe ser un archivo especifico para este HTML.
3. Link al sitio principal para volver a la página 1, este debe abrir en la misma ventana actual
4. Pie de página con los datos del alumno autor de sitio
5. Crear por lo menos un formulario, agregando las etiquetas (labels) correspondientes,  aplicando como mínimo estos controles:
- 4 controles para ingreso de textos
- 3 con opciones tipo radio
- 3 con selecciones tipo checkbox 
- 1 combo de opciones tipo datalist (se recomienda colocar los libros/películas/series que están en la página 1)
- 1 texto largo tipo textarea
- 1 botón
